# ShopMe

ShopMe is a modern e-commerce web application built with React, Vite, and Supabase. Users can browse products, add items to their cart, manage quantities, and place orders seamlessly.

## Features

* Home Page
* Products Page
* Product Catalog
* Shopping Cart Functionality
* Add to Cart / Remove from Cart
* Quantity Management
* Checkout Page
* Order Placement System
* Orders Page
* React Router Navigation
* Reusable React Components
* Responsive User Interface
* Supabase Database Integration

## Technologies Used

* React
* Vite
* React Router DOM
* Supabase
* JavaScript
* HTML
* CSS
