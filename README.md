# ShopMe

ShopMe is an e-commerce website developed using React. The website allows users to browse products, view different pages, and experience a modern shopping interface.

## Features

- Home Page
- Products Page
- Cart Page
- About Page
- React Router Navigation
- Reusable Components
- Modern UI Design

## Technologies Used

- React
- React Router DOM
- JavaScript
- HTML
- CSS
- Vite
